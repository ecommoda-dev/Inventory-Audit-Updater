ℹ️ عن الأداة — Inventory Audit
📋 وصف الأداة

أداة مراجعة وضبط الجرد — تتيح عرض أولويات الجرد تلقائياً (P0–P6) مع فلاتر متقدمة وجرد متسلسل ذكي. تستثني تلقائياً المنتجات غير المتتبعة (Inventory not tracked) وكل المنتجات ذات تاج Suspended من Worker.

المستخدمون

موظفو المخزن — جرد المنتجات وضبط الكميات + متابعة الأولويات

كيف تعمل
1تاب أولويات الجرد (🎯): يجلب كل المنتجات المتتبعة ويرتبها P0–P6، مع استثناء Suspended تلقائياً
2الفلاتر: تصفية بالأولوية / حالة آخر جرد / بحث SKU أو اسم المنتج
3اضغط SKU في القائمة → ينتقل لتاب الجرد ويحمّل المنتج مباشرة
4عد الرف: يدوي (✅ الجرد مظبوط / 🔧 أريد التعديل) أو بالسكانر (📷 ابدأ العد بالسكانر)
5بعد الجرد: popup يعرض باقي المقاسات و/أو التالي في الأولويات
6الجرد مظبوط → يُسجَّل التاريخ والموظف في Shopify + D1
7تعديل الكمية → يُطبَّق على Available في Shopify + تسجيل D1
الـ Endpoints
get_audit_prioritiesجلب المنتجات للـ Priority Queue — يستثني Untracked + Suspended
list_skusبحث SKU / اسم المنتج — يستثني Suspended، يرجع product.vendor
lookup_barcodeبحث بالباركود — يستثني Suspended، يرجع product.vendor
get_detailsأوردرات Unfulfilled + حالة التغليف S1/S2
adjust_inventoryتعديل Available + تسجيل D1
set_audit_dateتسجيل جرد مظبوط بدون تعديل

PRIORITY LOGIC
P0: avail < 0             خطأ محتمل
P1: avail=0 and comm>0   محجوز بالكامل
P2: avail=1-3 and comm>0 محجوز أقل من 3 قطع
P3: avail=1-3 and comm=0 من 1-3 قطع
P4: avail=4-6            من 4-6 قطع
P5: avail=7-10           من 7-10 قطع
P6: avail>10             أكبر من 10 قطع

SCANNER PIECE COUNTING (v4.0 — لا تغيير في الـ Worker)
• كل مسح لباركود = currentVariant.barcode → scannerCount++
• باركود مختلف أثناء العد → رفض + صوت/اهتزاز خطأ + إعادة العد الكامل لصفر
• إدخال يدوي اختياري يُجمع مع عدد السكانر (الإجمالي = سكانر + يدوي)
• "إنهاء العد" يقارن الإجمالي بـ currentShelfQty (نفس رقم الصندوق الأصفر):
    - تطابق تام → يفتح نفس Confirm Modal بتاع "الجرد مظبوط" مباشرة
    - فرق → يفتح adjust-panel مع delta معبأ تلقائياً (قابل للتعديل اليدوي) + ملاحظة تلقائية بتفاصيل العد
• لا endpoints جديدة — نفس set_audit_date / adjust_inventory الحاليين

PRODUCT CARD (v4.0.1)
• البراند = product.vendor من Shopify — لو فاضي، يعرض اسم المنتج الكامل كـ fallback
• الصورة قابلة للضغط → Popup بحجم الشاشة الكاملة (imageLightboxOverlay)
• زرارا "صفحة الـ SKU" و"سجل التعديلات" في عمود منفصل (product-nav-col) بجانب الصورة

EXCLUSIONS (Worker-side)
• Inventory not tracked -> Priority Queue only
• Tag: Suspended -> everywhere in tool
